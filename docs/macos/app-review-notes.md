# App Review notes

These notes describe the built-in Sample account in the current universal 1.1.0 build. The Sample is visible, removable and restorable; it is not a separate global demo mode. No reviewer credentials or private contact information belong in this file.

## English

Billing Helper for Cloudflare® is an independent native macOS menu bar app. Cloudflare® is a trademark and/or registered trademark of Cloudflare, Inc. in the United States and other jurisdictions; the app is not affiliated with, sponsored by or endorsed by Cloudflare. No app login is needed to explore the built-in Sample account. The Sample account is local, is clearly identified in the app, and contains simulated billing data; it is not connected to Cloudflare.

Open the app from the Dock or menu bar. On Overview, select the Sample account to inspect the current estimated cost, billing-cycle progress, cumulative usage-cost trend and product breakdown. The Budget alerts page lets you inspect the per-account budget controls. On Accounts, the Sample account can be removed and later restored explicitly.

To connect a real Cloudflare account, use Accounts to create a read-only API token, paste it into the secure field, find accounts and choose which to add. Real billing data comes from Cloudflare and is separate from the local Sample account. Testing this real API connection requires a reviewer-provided or separately authorized eligible Cloudflare account and token; no personal credentials are included in these notes.

The About page identifies the independent developer and offers an optional one-time App Store tip. The tip does not unlock features. The privacy policy is available from Settings.

## Review-access context

Apple's [App Review Guidelines §2.1](https://developer.apple.com/app-store/review/guidelines/#app-completeness) describe review access requirements, including prior approval for a built-in demo mode in certain login cases. This app's requested design is a visible, removable Sample account rather than a separate demo mode. The Sample does not exercise Cloudflare's live API; whether the resulting access is sufficient is for App Review to determine. No prior approval is claimed.
